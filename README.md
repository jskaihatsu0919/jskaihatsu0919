## より確実な運用（推奨）

ナレッジのファイルは「読める」だけで、そのままでは実行できません。
Claude が毎回コンテナに書き出す必要があり、`core.py` は約400行あるためトークンを消費します。

GitHub の **Public リポジトリ**に置けば、1コマンドで全ファイルが揃います。

```bash
curl -sSL https://raw.githubusercontent.com/<ユーザー名>/sanmei-kit/main/setup.sh | bash
```

手順は `04_GitHub運用ガイド.md` を参照してください。

> **Gist は使えません。** この環境のプロキシは `gist.githubusercontent.com` を
> `host_not_allowed` で拒否します（実測確認済み）。必ずリポジトリを作ってください。

## エンジンについて

石原さん関連8名の鑑定帳票を正解データとして逆解析し、196項目すべてで一致を確認しています。
判明した算出ルールの詳細は `engine/README.md` を参照してください。

**未解明として残っている項目**（帳票には載せない）

- 時墓格、白虎持旺格、従官格、官印相生格
- 主星の記号 `°` / `•`、ヘッダーの「5-7」等のコード
- 「生貴刑」と「貴刑」の使い分け

守護神テーブルは日干×月支の120セルのうち8セルが実帳票で実証済み、
残りは窮通宝鑑ベースの推定値です。`meta["守護神_実証済"]` で判別できます。
新しい帳票を入手したら、実証セルを増やして精度を上げてください。

## 検査を必ず通すこと

```bash
python3 /mnt/skills/public/pptx/scripts/office/validate.py 出力.pptx   # ファイル破損の検査
python3 qa.py 出力.pptx                                                # 境界・テキスト溢れの検査
```

`qa.py` の「はみ出し」は装飾（円相）の意図的なブリードなので無視して構いません。
「溢れ懸念」が出た場合は、文字数を減らすか箱を広げてください。
